## Sobre mim

Estou no último semestre de Análise e Desenvolvimento de Sistemas (ADS) na ENIAC, em São Paulo.
Atualmente atuo como estagiário em desenvolvimento backend, trabalhando com Python, Django, APIs
REST e chatbots com IA generativa para e-commerce. Meu foco está em análise de dados, IA e
automação de processos.
